Al ejecutar el comando "node server.js", Node.js inicia la aplicación y el servidor comienza a escuchar solicitudes en el puerto 3000. En la terminal aparece el mensaje "Servidor ejecutándose en puerto 3000", indicando que el servidor está funcionando correctamente. Al visitar la ruta "http://localhost:3000/estado" en el navegador, el servidor responde con un objeto JSON que informa que el servidor está activo y que el servicio corresponde a una API comunitaria.
