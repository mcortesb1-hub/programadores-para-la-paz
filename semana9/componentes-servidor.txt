Sistema operativo:
Es el software que administra los recursos del computador y permite ejecutar programas. También gestiona archivos, memoria y dispositivos del sistema.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Se utiliza para crear aplicaciones y servidores.

Aplicación "server.js":
Es el archivo donde se encuentra el código del servidor. Define las rutas y las respuestas que ofrecerá la aplicación a los usuarios.

Puerto:
Es el punto por el que el servidor recibe las solicitudes de los clientes. En esta práctica se utiliza el puerto 3000 para acceder a la aplicación.

Logs:
Son registros que almacenan información sobre la actividad del servidor, como errores, accesos y eventos. Ayudan a monitorear el funcionamiento y solucionar problemas.
