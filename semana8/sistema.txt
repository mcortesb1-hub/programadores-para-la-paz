El comando "uname -a" muestra información del sistema operativo, como el nombre del sistema, la versión del kernel y la arquitectura del equipo. El comando "whoami" muestra el nombre del usuario que está utilizando el sistema. Conocer esta información es útil al administrar un servidor porque permite verificar el sistema operativo instalado, identificar el usuario con el que se están ejecutando los comandos y facilitar tareas de administración, configuración y solución de problemas.
