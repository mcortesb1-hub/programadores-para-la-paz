Las dos tareas del backlog que realizaría primero son:

1. Como ciudadano quiero registrar una incidencia para dejar evidencia del caso.
2. Como coordinador quiero recibir una alerta en Telegram para revisar un nuevo reporte.

Estas tareas son las más importantes porque permiten registrar la información y notificar de inmediato que existe un nuevo reporte para darle seguimiento.

Para mí, una tarea está terminada cuando cumple con estos criterios:

- Funciona correctamente.
- Fue probada y no presenta errores.
- Quedó registrada en Git con sus cambios guardados.
