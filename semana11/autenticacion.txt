El login es el proceso mediante el cual un usuario se identifica en una aplicación usando sus credenciales. Esto permite verificar su identidad antes de acceder a determinadas funciones. Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes dentro del sistema. De esta manera, solo los usuarios autorizados pueden acceder a ellas. No deben exponerse públicamente contraseñas, documentos de identidad, números de teléfono, direcciones, claves de API, tokens ni otros datos sensibles de la comunidad.
